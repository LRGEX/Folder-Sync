# Installation

## Quick Start
1. Download `LRGEXSync.exe` from [Releases](https://github.com/LRGEX/Folder-Sync/releases)
2. Place it in a **cloud-synced folder** (OneDrive, Google Drive, etc.)
3. Double-click to launch
4. Pick your sync folder (same cloud folder)
5. Right-click any folder → "Sync folder (LRGEX)" to add it

## Requirements
- Windows 10/11 (x64)
- No dependencies (static CRT, standalone exe)
- A cloud-synced folder for backups to survive format

## First Run
The app asks you to pick a "home" folder. This is where:
- The exe lives
- Backups are stored (`backup/`)
- Snapshots live (`_versions/`)
- Internal state (`.lrgex/`)

**Recommended:** OneDrive folder so backups sync to the cloud automatically.
